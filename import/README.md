# Drop song files here

Put Guitar Pro (`.gp5`, `.gp4`, `.gp3`) or MusicXML (`.musicxml`, `.xml`, `.mxl`)
files in this folder and push to `main`. The "Publish songs" workflow turns each
one into a song file for the app and publishes it. See the main README for details.

Keep the files here: editing a file and pushing it again updates the same song.
